## Where to get help

- **Quid scio? content, layout, or broken links.** Open a site issue with the affected page URL and what you expected to see. [Quid scio? issue tracker](https://github.com/quidscio/quidscio.github.io/issues)
- **A bug in the upstream Midnight theme.** Check the existing Midnight issues and include a reproducible example if you report a new one. [Midnight issue tracker](https://github.com/pages-themes/midnight/issues)
- **GitHub Pages or Jekyll.** Consult the provider's documentation for build, deployment, or local preview questions. [GitHub Pages documentation](https://docs.github.com/en/pages) · [Jekyll community](https://talk.jekyllrb.com/)
