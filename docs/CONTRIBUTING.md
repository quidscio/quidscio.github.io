# Contributing to Quid scio?

This repository maintains the Quid scio? site and its Jekyll templates. See the [README](../README.md) for WSL setup, local preview, and GitHub Pages publishing.

## Prepare a change

1. Keep each change focused. Preserve existing post URLs and original publication dates when editing published articles.
2. For an article, follow the [post-authoring procedure](Post-authoring-procedure_md-pages-LI.md). Keep the Markdown and accompanying image assets together.
3. Preview affected pages locally. For template or stylesheet changes, check an article and a standard page at desktop and mobile widths.
4. Run `script/cibuild` in WSL before submitting the change. Include the results in the pull request. For a visible layout change, include screenshots when they help explain it.

The repository's contribution standards are in the [Code of Conduct](CODE_OF_CONDUCT.md). See the [support guide](SUPPORT.md) for where to report site and upstream theme issues.
